# Compatibility

Official target for 1.0.0:

- Linux x86_64
- OpenCode stable 1.18.x
- Python 3
- Node.js + npx (for shadcn MCP)
- git, curl, tar

Not claimed tested: macOS, Windows, other OpenCode majors.

Optional: Chromium (`chromium`, `chromium-browser`, `/snap/bin/chromium`), `gh`, browser-act, serena, semgrep, osv-scanner, gitleaks.

Codebase Memory artifact is Linux amd64 only.
