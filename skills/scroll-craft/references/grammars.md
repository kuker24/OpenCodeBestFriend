# Page grammars

Pick **one**. Do not mix forbids. Do not turn every grammar into Hero → Features
→ About → CTA.

## 1. Filmic One-Shot

**Fits:** one linear argument, one emotional arc.

**Structure:** continuous handoff, no chapter chrome, one entry.

**Nav / open / close:** minimal bar; full-bleed or layered open; pinned close
that holds the CTA.

**Leans on:** `pin`, `drift`, `kinetic`, optional `scrub` (tier 3).

**Forbids:** jump index, hard chapter cuts, tool chrome, multiple entry points.

## 2. Chaptered Editorial

**Fits:** long-form method, manifesto, research.

**Structure:** chapters as units, hard cuts, asymmetric spreads.

**Nav / open / close:** folio/chapter title, no fixed marketing bar; title-page
open (type first); colophon close, CTA as running text.

**Leans on:** `flow` + `in`, `reveal` at boundaries.

**Forbids:** continuous `drift` gradient, full-bleed video hero, magnetic CTA,
media bleeding under type.

## 3. Live Surface

**Fits:** software whose demo is the argument.

**Structure:** the real surface, scroll driving state. Copy lives in product
idiom (labels, empty states, status).

**Nav / open / close:** app chrome is nav; surface already in a state; close is
a real input.

**Leans on:** `pin`, `--sc-p` for custom state, `count` on real figures.

**Forbids:** marketing hero, kinetic headline stacks, fake dashboards. If panels
cannot compute, pick another grammar. Label sample data.

## 4. Continuous World

**Fits:** travel through a place (supply chain, geography, process stages).

**This skill does not implement it.** Write story, waypoints, feeling curve, and
direction, then hand off to `scroll-world`. Do not copy worldflight, chain
pipeline, or video stitching. Do not assume every 3D world needs video.

**Forbids (here):** pinned-act fake worlds, `data-sc-mode="worldflight"` as the
OCBF implementation path.

## 5. Typographic Poster

**Fits:** the asset is a sentence; weak or absent photography.

**Structure:** scale contrast does the work of imagery.

**Nav / open / close:** wordmark in the composition; one line at extreme scale
(`<h1>` real); close inverts to the smallest type and a plain link.

**Leans on:** `kinetic`, `pin` + `--sc-p` scale, `reveal`.

**Forbids:** photographic ground as the main image, card rails, decorative motion
that outruns type.

## 6. Gallery / Catalog

**Fits:** options, portfolio, menu, materials.

**Structure:** objects with a shared label schema (facts, not pitch).

**Nav / open / close:** object index that jumps; object one already labelled;
close is last object or an inquiry plate in the same schema.

**Leans on:** `pan`, per-object `reveal`.

**Forbids:** a single hero claim, persuasion in labels. Rail content must remain
reachable on mobile and reduced motion.

## 7. Split Stage

**Fits:** two-sided argument (before/after, cost/saving).

**Structure:** both columns present and loaded the whole way; scroll tips the
balance.

**Nav / open / close:** divider is chrome; 50/50 first screen; close is the
collapse to the winning column.

**Leans on:** `pin` + `--sc-p` on the divider, `reveal` per side.

**Forbids:** one decorative column, full-bleed before resolve, `pan` as spine.

## 8. Rhythmic Cutlist

**Fits:** energy brands; pulse rather than argument.

**Structure:** many short unpinned cuts. No dwell, no pin.

**Nav / open / close:** loud bar; first screen already cutting; abrupt full-bleed
CTA.

**Leans on:** `flow` + `in`, short `reveal`.

**Forbids:** `pin`, long spans, slow easing. If the peak wants a hold, put it in
persistent chrome, not a pinned act.
