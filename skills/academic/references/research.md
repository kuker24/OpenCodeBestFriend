# Mode: Academic Research

Literature survey, claim-to-source mapping, and evidence synthesis.

## Objective

Build a verified, structured literature base that maps scholarly questions to peer-reviewed findings, methodologies, and consensus or contention.

## Procedure

1. **Scope Definition:**
   - Define primary research questions (RQs) and sub-questions.
   - Establish inclusion/exclusion boundaries (publication window, methodology types, domain scope).

2. **Literature Discovery:**
   - Search scholarly databases, pre-print archives, or open access repositories.
   - Record canonical identifiers: Title, Authors, Year, Journal/Conference, DOI or stable URL.

3. **Systematic Evidence Lineage (SLR / PRISMA Inspired):**
   - Record query strings and database sources used for each search phase.
   - Track screening stages: Identification -> Screening (Title/Abstract) -> Eligibility (Full text) -> Included.
   - Document exclusion rationales explicitly (e.g. out-of-scope domain, missing empirical data, non-peer-reviewed blog).

4. **Claim-Source Matrix:**
   - Extract core claims from each candidate paper.
   - Distinguish empirical findings from author hypotheses or discussion commentary.
   - Tag agreement, conflict, or gaps across papers.

5. **Verification Gate:**
   - Verify DOI resolution or canonical landing page.
   - If a source was suggested but cannot be independently verified via accessible search/tools, label it explicitly as `[UNVERIFIED: <reason>]`. Never invent a plausible-sounding citation.

6. **Output Artifact:**
   - Output an annotated bibliography or literature synthesis table with columns:
     `Paper | Key Finding | Methodology / Dataset | Limitations | Relation to RQ`.
